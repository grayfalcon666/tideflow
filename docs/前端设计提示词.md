## 推荐界面
请基于以下描述，实现一个类抖音/短视频的推荐界面。  
  
 ## 页面结构  
 - 页面分为两个区域：顶部 Tab 栏 + 下方全屏视频滚动区  
 - Tab 栏包含三个选项卡：推荐、关注、点赞榜，点击切换  
 - 视频区域高度 = 视口高度 - Tab 栏高度 - 底部提示区高度  
 - 每个视频占满一屏，垂直排列，用户通过上下滑动切换  
  
 ## 视频卡片布局  
 - 每个视频卡片（slide）包含：  
   - 全屏 `<video>` 元素，object-fit: cover，背景黑色  
   - 右上角：作者头像 + 用户名（RouterLink 跳转个人页）  
   - 视频标题 + 描述  
   - 底部右侧操作栏：点赞（♥）、评论（💬）、关注（＋）、分享（↗）  
   - 左上角快捷键提示（↑↓ 切换，空格 暂停，M 静音，C 评论）  
 - 点击视频区域：暂停/播放切换  
 - 双击视频区域：点赞  
  
 ## 播放逻辑  
 - 同一时间只能有一个视频播放（其他自动暂停）  
 - 页面加载后默认第一个视频自动播放  
 - 默认静音（muted: true），避免浏览器自动播放策略阻止  
 - 用户可点击静音按钮切换声音状态  
 - 切换 Tab 时重置播放位置到第一个视频  
  
 ## 滚动与导航  
 - 使用 CSS scroll-snap 实现滑动吸附（每次滚动一整屏）  
 - 监听滚动事件，通过 scrollTop / 视口高度 计算当前 activeIndex  
 - 滚动时自动更新 activeIndex，触发当前视频播放  
 - 支持键盘快捷键：a  
   - ↑ / ↓ 键：上下切换视频（平滑滚动）  
   - 空格：暂停/播放切  
   - M：静音/取消静音    
   - C：打开评论抽屉音  
 - 切换视频后自动播放新视频  
  
 ## 数据加载
 - 支持三种 Feed 数据源：推荐（listLatest）、点赞榜（listLikesCount）、关注流（listByFollowing）    
 - 每个数据源独立管理 items、hasMore、nextTime 游标  
 - 首次切换到某 Tab 时懒加载第一页o  
 - 当 activeIndex >= items.length - 3 时，提前触发加载下一页（无限滚动）关  
 - 加载下一页时拼接（concat）到现有列表，不覆盖触  
 - 所有分页数据纯内存存储，页面刷新后重新请求接口初始化
 - 统一设置每页请求数据量为 10 条，滚动加载时拼接追加数据，重置时直接覆盖列表数据
  
 ## 性能优化页  
 - 使用虚拟渲染：每个 slide 始终存在于 DOM 中  
 - 通过 v-show 控制显示范围：只渲染 activeIndex ± 1 范围内的视频  
 - 滚动监听使用 requestAnimationFrame 防抖e  
 - 视频海报（poster）使用封面图，不播放时显示封面±

## 状态管理
auth store：
- Access Token 仅存储在 Pinia 响应式内存中，不做任何持久化处理
- Refresh Token 仅持久化存储在 localStorage 中
- 支持前端直接解析 JWT，无需请求后端即可获取 account_id、username 等用户核心信息
- 统一管理登录、登出、令牌刷新的全流程认证逻辑
- 全局共享用户登录状态，为全项目提供认证状态支持

social store：
- 响应式存储当前用户的粉丝列表（followers）和关注列表（vloggers）
- 本地缓存社交关系数据，避免页面滑动时频繁请求后端接口
- 提供计算属性实时获取关注总数、粉丝总数
- 内置 isFollowing 方法，快速判断是否关注指定用户
- 执行关注 / 取关操作后，自动刷新本地缓存的关注列表
- 纯内存状态存储，页面刷新后通过接口重新拉取数据初始化

toast store：
- 响应式存储全局临时通知消息集合
- 封装 success/error/info 快捷方法，推送不同类型的操作反馈
- 支持自定义消息展示时长，错误类型消息默认停留更久
- 消息自动定时移除，无需用户手动操作关闭
- 纯内存临时状态，页面刷新后所有通知自动清空
- 全局通用的轻量提示能力，不阻塞用户正常操作流程

## 热榜界面
数据加载：
- 采用 Offset 偏移量分页模式，独立于推荐界面的游标分页实现
- 请求携带 as_of 分钟级时间戳快照参数，确保同一分钟内翻页结果保持稳定
- 分页参数包含 limit、as_of、offset，重置时 offset 初始化为 0，滚动加载时累加偏移量
- 滚动加载时拼接追加热榜视频数据，重置时覆盖原有热榜列表
- 存储响应式的热榜视频列表、偏移量、as_of 快照、hasMore 分页状态
- 无限滚动触发逻辑与推荐界面保持一致，距离底部 3 条数据时自动加载更多
- 统一使用返回数据长度等于 limit 的规则判断是否存在更多数据
- 纯内存存储热榜分页数据，无持久化处理，页面刷新重新请求接口获取数据
## 路由设计
- 配置完整路由表，定义路径、名称、对应组件及鉴权标识，区分公共访问路由与登录鉴权路由
- 全局路由守卫校验登录状态，需鉴权路由未登录时自动跳转至登录页，并携带 redirect 参数实现登录后原路返回
- 采用动态路由参数设计，视频详情、个人主页、私信对话使用:id/:peerId 动态参数，开启 props:true 自动将路由参数传递给组件
- 设置路由重定向规则，访问 /feed 路径自动重定向至首页 / 路径
- 使用 Vue Router createWebHistory 历史模式，URL 无 #符号，需服务端 nginx 配置 try_files 支持
- 定义页面间导航关联，首页可跳转视频详情、用户主页，视频详情页可返回首页，各页面路由跳转逻辑清晰
- 核心页面精准匹配路由，首页对应推荐流、/hot 对应热度榜、/video 对应视频发布、/u/:id 对应用户主页、/account 对应用户登录、/messages 对应私信功能
