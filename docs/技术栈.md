## 后端技术栈
- 核心开发语言为 Go 1.24.5
- HTTP 服务框架采用 Gin v1.11.0
- 数据库 ORM 框架使用 GORM v1.31.1
- 集成 gorm.io/driver/mysql v1.6.0 与 go-sql-driver/mysql v1.8.1 作为 MySQL 驱动
- 数据库迁移方案采用 GORM AutoMigrate 自动迁移，无需手动编写 SQL 脚本
- 消息队列客户端使用 rabbitmq/amqp091-go v1.10.0
- 缓存客户端采用 redis/go-redis/v9 v9.17.2
- 身份鉴权使用 golang-jwt/jwt/v5 v5.3.0
- 加密工具依赖 [golang.org/x/crypto](https://golang.org/x/crypto) v0.40.0
- 配置管理工具使用 Viper v1.18.2，支持多环境配置、热加载与配置文件读取
- 配置文件解析使用 gopkg.in/yaml.v3 v3.0.1
- 本地内存缓存使用 patrickmn/go-cache v2.1.0
- 并发控制依赖 [golang.org/x/sync](https://golang.org/x/sync) v0.16.0
- API 文档工具集成 swag v1.16.3 与 gin-swagger v1.5.0，自动生成 Swagger UI 在线接口文档

## 前端技术栈
- 核心框架为 Vue ^3.5.24
- 路由管理使用 Vue Router ^4.6.4
- 全局状态管理使用 Pinia ^3.0.4
- 类型系统采用 TypeScript ~5.9.3
- 项目构建工具为 Vite v7.2.5
- Vue 编译插件使用 @vitejs/plugin-vue ^6.0.1
- 类型检查工具使用 vue-tsc ^3.1.4
- UI 组件框架使用 Quasar ^2.16.0
- 集成 Quasar Vite 插件适配 Vue3 项目开发
- 包管理工具使用 pnpm，高效管理项目依赖

## 基础设施
- 数据库使用 MySQL 8.0 版本 Docker 镜像
- 缓存服务使用 Redis 7-alpine 版本 Docker 镜像
- 消息队列使用 RabbitMQ 3-management 版本 Docker 镜像
- 后端 Docker 基础镜像为 Alpine 3.21
- 前端容器部署使用 Nginx latest 版本

## 开发工具
- 版本控制工具使用 Git，实现代码管理、分支协作与版本回溯
